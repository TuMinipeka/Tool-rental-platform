# Fotografías requeridas para el catálogo

## Formato de entrega

- Una fotografía principal por herramienta como mínimo; idealmente tres por publicación: vista completa, detalle funcional y accesorios incluidos.
- Formato WebP o JPEG, perfil sRGB, relación `4:3` y resolución mínima `1600 × 1200 px`.
- Fondo neutro o contexto de trabajo ordenado, luz uniforme y herramienta completa sin recortes.
- No incluir personas identificables, placas, documentos, teléfonos, marcas de agua ni textos promocionales.
- Las imágenes deben ser propias o contar con autorización de uso. No descargar fotografías comerciales sin licencia.
- Mantener el mismo encuadre y escala visual en toda la serie. El archivo principal usa el sufijo `-01` y las vistas adicionales `-02`, `-03`.
