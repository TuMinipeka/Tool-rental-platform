# Sistema visual de Tool Rental

## Dirección

Tool Rental se presenta como una plataforma industrial confiable, clara y enérgica. La interfaz toma referencias de placas de calibración, señalización de obra y fichas técnicas, sin imitar visualmente a otra marca.

La identidad usa una armonía triádica con funciones estables:

- Azul cobalto (`#2354C6`): confianza, navegación y superficies principales.
- Naranja seguridad (`#F26A2E`): llamadas a la acción y puntos de atención.
- Verde técnico (`#188A58`): disponibilidad, confirmación y estados favorables.
- Carbón (`#17201D`) y neutros cálidos: texto, estructura y descanso visual.

El estado nunca depende únicamente del color: debe incluir texto, icono o ambos.

## Tipografía

- Archivo Variable: títulos, cifras y mensajes de alto impacto.
- Public Sans Variable: navegación, formularios, tablas y texto corrido.
- Los títulos usan peso alto y espaciado compacto; el cuerpo prioriza lectura y contraste.

## Forma y composición

- Contenedor de contenido máximo: `1240px`; la navegación puede extenderse hasta `1360px`.
- Radios entre `10px` y `16px` según la escala de la superficie; las píldoras se reservan para filtros y estados.
- Las tarjetas usan bordes tenues y elevación corta al interactuar.
- La retícula técnica y la línea de calibración son recursos de marca, no decoración repetitiva.
- Solo la línea de calibración del inicio emplea una animación de entrada, y respeta `prefers-reduced-motion`.

## Interacción y accesibilidad

- Todo control interactivo muestra foco visible.
- Las tarjetas de herramientas se activan con puntero, Enter o barra espaciadora.
- Los formularios conservan etiquetas visibles y errores textuales.
- Objetivo mínimo táctil: `44 × 44px`.
- La versión móvil conserva orden de lectura, resumen de precio y acciones esenciales.

## Contenido y confianza

- El pago siempre se identifica como simulación.
- Cuando la API no está disponible, catálogo y acceso declaran de forma visible el modo demostrativo y no presentan sus datos como reales.
- Nunca se solicita número completo de tarjeta ni CVV; solo red, vencimiento y últimos cuatro dígitos.
- Valores comerciales no aprobados se muestran como pendientes, nunca como condiciones definitivas.
- Fotografías futuras deben mostrar herramientas reales en uso o inspección, con iluminación natural, sin marcas de agua y con licencia de uso.
- Las ilustraciones CSS incluidas actualmente son placeholders demostrativos; deben sustituirse por fotografías aprobadas antes de presentar el catálogo como contenido real.
